# Задание для Claude Code

Перед отправкой:
1. Скопируйте папку `particle-morph/` в исходники сайта, а `models/` в папку статики.
2. Заполните строки в квадратных скобках.
3. Вставьте в Claude Code всё, что ниже линии.

---

Встрой на сайт готовый 3D-компонент `ParticleMorphScene`: скульптуру из частиц, которая при прокрутке превращается по очереди в 5 объектов.

**Где лежит:**
- компонент: [путь, например `src/components/particle-morph/`]. Сначала прочитай `CLAUDE.md` в этой папке, там правила и API;
- модели: [путь, например `public/models/`], пять файлов `.glb`;
- если рядом лежат `INTEGRATION.md` и `examples/` из пакета, используй их как образец.

**Стек сайта:** [например: Next.js 15 (App Router) / Astro / Vite + React / обычный HTML без сборщика]

**Где на странице:** [например: отдельная секция после блока «О себе», на всю ширину экрана]

**Что сделать:**
1. Установи зависимости точно этих версий: `three@0.187.0`, `three-mesh-bvh@0.9.18`, `gsap@3.15.1`. Если сайт без сборщика, подключи их через import map, как в `examples/vanilla/`.
2. Сверстай секцию:
   - внешний блок высотой `900vh`. Это длина прокрутки, за которую проходят все 5 объектов, примерно два экрана на каждое превращение;
   - внутри него блок `position: sticky; top: 0; height: 100vh`, в который монтируется компонент;
   - фон в этом месте страницы белый.
3. Подключи компонент так же, как в `examples/`:
   - `new ParticleMorphScene(stage, { models: SHOWCASE_MODELS('<путь к папке, где лежит models/>'), cssBlendTarget: 'container' })`, затем `await scene.load()`;
   - прокрутку привяжи через `ScrollController`, `trigger` — внешний блок секции;
   - загрузку начинай, когда секция приближается к экрану (`IntersectionObserver` с запасом ~1 экран). Анимацию ставь на паузу (`scene.stop()` / `scene.start()`) отдельным `IntersectionObserver` без запаса, когда секция уходит с экрана;
   - пока модели грузятся, покажи в секции простой индикатор загрузки, без собственного дизайна.
4. Если сайт SPA (React, Next.js и т. п.): при размонтировании вызывай `scroll.dispose()` и `scene.dispose()`. В Next.js компонент только клиентский (`'use client'` и динамический импорт), без SSR.
5. Настройки эффекта уже подобраны и зашиты в `config.js`. Ничего в них не меняй и не передавай их повторно.

**Не делай:**
- не меняй файлы внутри папки компонента. Если без этого никак, сначала спроси;
- не вешай `transform`, `filter`, `opacity < 1`, `isolation` или `z-index` на родителей sticky-блока: это ломает sticky и режим наложения;
- не создавай второй экземпляр компонента на странице.

**Проверь в браузере:**
- при прокрутке секции по очереди появляются: конь (начало), турник (25%), катана (50%), синтезатор (75%), MacBook (конец). При прокрутке назад всё идёт в обратном порядке;
- частицы чёрные на белом фоне. Если они не видны (белые на белом), значит родитель создаёт stacking context, см. `CLAUDE.md`;
- фигура слегка поворачивается за мышью; при наведении частицы разлетаются и собираются обратно;
- нет ошибок в консоли; при уходе со страницы и возврате (SPA) нет утечек и дублей canvas;
- остальная страница прокручивается как раньше, высота секции учитывается.
