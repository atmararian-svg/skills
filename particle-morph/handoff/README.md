# 3D-скульптура из частиц: пакет для внедрения

Пакет добавляет на сайт секцию, где скульптура из 40 000 частиц при прокрутке превращается по очереди в пять объектов:

**Шахматный конь → турник → катана → синтезатор → MacBook**

Фигура слегка поворачивается за курсором. При наведении частицы разлетаются, затем собираются обратно. Финальные настройки уже зашиты в код, поэтому ничего настраивать не нужно.

## Что внутри

| файл / папка | зачем |
|---|---|
| `README.md` | этот файл, начать отсюда |
| `CLAUDE_CODE_PROMPT.md` | готовое задание для Claude Code: скопировать и вставить |
| `INTEGRATION.md` | подробная инструкция по внедрению: вёрстка, скролл, загрузка, SPA, подводные камни |
| `particle-morph/` | сам компонент; копируется в исходники сайта как есть. Внутри `CLAUDE.md`, который Claude Code прочитает сам |
| `models/` | пять 3D-моделей (.glb, ~30 МБ); кладутся в статику сайта (`public/models/`) |
| `examples/vanilla/` | рабочий пример на чистом HTML, без сборщика |
| `examples/react/` | React-компонент секции; подходит и для Next.js |
| `TECHNICAL.md` | техническое описание: архитектура, все параметры, API |

## Самый короткий путь (Claude Code)

1. Скопировать `particle-morph/` в исходники сайта, например в `src/components/particle-morph/`.
2. Скопировать `models/` в папку статики, например в `public/models/`.
3. Открыть Claude Code в проекте сайта и вставить текст из `CLAUDE_CODE_PROMPT.md`. Перед этим нужно заполнить в нём две строки в квадратных скобках: где на странице должна быть секция и какой у сайта стек.

## Если внедрять вручную

1. Установить зависимости:
   ```bash
   npm install three@0.187.0 three-mesh-bvh@0.9.18 gsap@3.15.1
   ```
   Если сайт без сборщика, см. `examples/vanilla/`: там зависимости подключаются с CDN через import map.
2. Скопировать `particle-morph/` и `models/`, как описано выше.
3. Сверстать секцию и подключить компонент по образцу из `examples/` (React или vanilla). Подробности в `INTEGRATION.md`.

## Что важно знать заранее

- **Фон.** Эффект рассчитан на белый фон: частицы рисуются чёрными за счёт режима наложения `difference`. На тёмном фоне частицы будут белыми, на цветном инвертируются.
- **Вес и загрузка.** Модели весят ~30 МБ. После скачивания браузер ещё 3–4 секунды строит облака точек, и в это время страница не отвечает. Поэтому загрузку стоит запускать заранее, когда секция приближается к экрану; в примерах это уже сделано.
- **Телефоны.** Прототип делался под десктоп и на телефонах не тестировался. В `INTEGRATION.md` есть рекомендация для мобильных.
- **Лицензии моделей.** Конь, катана и турник взяты со Sketchfab по лицензии Sketchfab Standard. У синтезатора и MacBook информации о лицензии нет. Перед запуском сайта лицензии нужно проверить.
